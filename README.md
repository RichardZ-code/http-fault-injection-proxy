# HTTP Fault Injection Proxy

A planned Go HTTP tool for local and CI testing of client behavior under controlled latency, synthetic 5xx responses, and upstream deadlines.

The project is at the design stage. Implementation, runnable examples, CI, containers, benchmarks, and release artifacts are not yet available. The proposed v0.1.0 contract awaits user acceptance and a focused independent design review.
